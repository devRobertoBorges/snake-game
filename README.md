# 🐍 Snake Game

Um jogo clássico de **Snake**, inspirado nos jogos de celulares antigos, desenvolvido com **HTML, CSS e JavaScript puro**.

O projeto foi desenvolvido como forma de praticar lógica de programação, manipulação do Canvas, arrays, funções, eventos de teclado e movimentação de objetos.

## 🎮 Funcionalidades

- Movimento automático da cobra
- Controle pelas setas do teclado
- Cobra formada por partes armazenadas em um array
- Comida gerada em posições aleatórias
- Crescimento da cobra ao comer
- Detecção de colisão com a comida
- Detecção de colisão com as paredes
- Tela de início do jogo
- Estrutura preparada para Game Over e reinício

## 🎯 Objetivo do projeto

O objetivo principal deste projeto foi praticar JavaScript através da criação de um jogo simples, entendendo a lógica por trás de cada funcionalidade em vez de apenas utilizar código pronto.

A construção foi feita progressivamente:

```text
Canvas
  ↓
Quadrado
  ↓
Movimentação
  ↓
Controle pelo teclado
  ↓
Corpo da cobra
  ↓
Movimentação do corpo
  ↓
Comida
  ↓
Colisão
  ↓
Crescimento da cobra
  ↓
Limites do jogo
```
